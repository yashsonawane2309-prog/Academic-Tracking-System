# Academic Tracking System

## 📌 Overview
This is a Java-based Academic Tracking System designed to manage student academic records including marks, attendance, notifications, and performance reports.

## 🚀 Features
- Student management
- Marks entry and calculation
- Attendance tracking
- Exam and performance reports
- Notifications system

## 🛠️ Technologies Used
- Java
- JDBC (if used)
- MySQL (if used)
- Eclipse IDE

## 📂 Project Structure
- src → Source code
- lib → External libraries
- bin → Compiled files
